# Into-the-Leap

[![Watch the Trailer] ( https://www.youtube.com/watch?v=fKj7OucdLHw )



**Underwater Survival Game | Unreal Engine 5.7, Blueprints**

Developed a 3D underwater survival game in Unreal Engine 5.7, implementing gameplay mechanics and AI-driven enemy behaviors using Blueprint Visual Scripting.

Developments made by me:

- Designed enemy AI systems using **Behavior Trees, Blackboards, AI Controllers, Services, and Tasks**, enabling dynamic player tracking and decision-making.
- Implemented **NavMesh-based pathfinding**, automatic obstacle traversal, and custom 3D pursuit mechanics for underwater enemies.
- Developed interactive environments featuring **Chaos Destruction**, physics-based interactions, underwater movement, and collision detection.
- Integrated player survival mechanics, including an oxygen system, enemy encounters, and Game Over conditions.
